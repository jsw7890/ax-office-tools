# 화면 구성

2026-11-06에 동작하는 화면 기준입니다. 문구는 화면에 있는 그대로입니다.

## 공통

- 왼쪽 위 이름: 사내 업무 도구. 누르면 첫 화면으로 갑니다.
- 오른쪽 위: 들어가기 전에는 "로그인". 들어간 뒤에는 "김민지 · 직원" 또는 "박관리 · 관리자"와 "로그아웃".
- 로그인 후 첫 화면에서는 "샘플 계정으로 들어가기" 버튼이 보이지 않습니다. 로그아웃하면 다시 보입니다.

## 직원 메뉴

로그인하지 않았을 때도 같은 네 개입니다.

| 메뉴 | 주소 | 화면 |
| --- | --- | --- |
| 회의실 | /rooms | 회의실 시간표. 이전 날, 날짜, 다음 날이 한 줄입니다. |
| 내 예약 | /rooms/mine | 내 예약 목록. 예약됨이면 "취소"가 있습니다. |
| IT helpdesk | /helpdesk | 제목 "IT helpdesk"와 초록색 "문의 등록"이 한 줄입니다. |
| 규정 챗봇 | /chat | 조문 검색. 아래 안내 두 줄이 항상 있습니다. |

문의 등록 주소는 /helpdesk/new 이고, 문의 하나는 /helpdesk/번호 입니다.

규정 챗봇에 항상 보이는 문장:

- 공개 자료 기반 샘플이며 실제 회사 규정이 아닙니다. 법률 자문이 아닌 참고용입니다. 고객·개인정보는 입력하지 마세요.
- 향후 LLM 추가를 통해 답변 방식 개선 예정

답은 저장된 조문만 사용합니다. 유료 AI는 호출하지 않습니다.

## 관리자 메뉴

관리자로 들어가면 메뉴는 이 세 개만 있습니다.

| 메뉴 | 주소 | 화면 |
| --- | --- | --- |
| IT helpdesk | /helpdesk | 직원과 같은 문의 화면 |
| 회의실 관리 | /admin/rooms | 회의실 목록, 추가, 수정 |
| IT helpdesk 현황 | /admin/tickets | 전체 문의. 상태와 분류로 거릅니다. |

관리자 로그인 직후 열리는 화면은 IT helpdesk 현황입니다. 직원 로그인 직후는 회의실 시간표입니다.

## 첫 화면

주소는 / 입니다. 제목은 "직원용 샘플 도구"이고, 카드 세 장(회의실, IT helpdesk, 규정 챗봇)이 있습니다.

## 로그인

주소는 /login 입니다. "직원 김민지로 로그인", "관리자 박관리로 로그인" 버튼이 있습니다. 비밀번호 칸은 없습니다.
