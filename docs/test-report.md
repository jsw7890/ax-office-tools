## 보안 시나리오

- 저장소 파일에서 API 키 형태를 검색했고 발견되지 않았다.
- 제목·내용에 스크립트와 SQL 문장을 넣어도 그대로 저장되고 표는 삭제되지 않았다.
- `LLM_PROVIDER=claude`로 두어도 네트워크 호출 없이 거절했다.
- 화면 서버에서 겹치는 예약은 409로 거절됐다.

## 확인하지 않은 것

- 클라우드 로그인(Supabase 이메일)과 유료 AI는 연결하지 않았다. 권한 규칙은 이 PC의 로컬 데이터베이스에 같은 SQL을 적용해 확인했다.
- 외부 AI 답변 품질은 호출하지 않았으므로 확인하지 않았다.
