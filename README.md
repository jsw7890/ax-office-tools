# 사내 업무 도구

직원 약 50명 규모를 가정한 연습용 웹 화면입니다. 회의실 예약, IT helpdesk, 규정 질문을 한 앱에서 써 볼 수 있습니다. 이름과 문의 내용은 가짜 샘플이며, 실제 회사 자료를 쓰지 않습니다. 포트폴리오 레퍼런스용입니다.

## 이 버전에서 되는 것

- 회의실 예약. 방별 시간표, 예약, 취소, 같은 시간 겹침 방지.
- IT helpdesk. 문의 등록, 내 문의, 댓글. 관리자는 상태를 바꿉니다.
- 규정 챗봇. 저장된 근로기준법 조문을 찾아 보여 줍니다. 외부 AI는 호출하지 않습니다. 화면에는 "향후 LLM 추가를 통해 답변 방식 개선 예정"이 항상 보입니다.
- 로그인과 로그아웃. 로그인 후에는 첫 화면의 "샘플 계정으로 들어가기" 버튼이 숨습니다.

## 연결하지 않은 것

- 클라우드 로그인(Supabase 이메일 로그인)은 붙이지 않았습니다. 이 컴퓨터 안의 데이터베이스로만 들어갑니다.
- 유료 AI는 호출하지 않습니다. 키를 넣어도 승인 전에는 네트워크로 나가지 않습니다.

## 실행

Node.js가 설치된 컴퓨터에서, 이 폴더를 연 다음 한 번만 설치합니다.

```powershell
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 3000번이 이미 쓰이고 있으면 아래처럼 다른 번호로 켤 수 있습니다.

```powershell
npm run dev -- --port 3456
```

그러면 주소는 http://localhost:3456 입니다.

## 샘플 계정

비밀번호는 없습니다.

| 누구 | 이메일 | 들어간 뒤 |
| --- | --- | --- |
| 직원 김민지 | staff@example.com | 회의실 시간표 |
| 관리자 박관리 | admin@example.com | IT helpdesk 현황 |

로그인 화면의 버튼 두 개로 들어갈 수 있습니다. 다른 이메일은 거절됩니다.

## 화면

위쪽 메뉴는 역할마다 다릅니다.

- 직원(로그인 전 메뉴도 같음): 회의실, 내 예약, IT helpdesk, 규정 챗봇
- 관리자: IT helpdesk, 회의실 관리, IT helpdesk 현황

오른쪽 위에는 로그인 전이면 "로그인", 들어간 뒤면 이름과 "로그아웃"이 있습니다.

화면 목록과 각 화면에서 하는 일은 [docs/screens.md](docs/screens.md)에 있습니다.

## 쓰는 방법

- 회의실: 날짜를 고르고 빈 칸의 "예약"을 누릅니다. 제목과 끝나는 시간을 고릅니다. 운영 시간은 09:00–18:00, 30분 단위입니다. 같은 방을 같은 시간에 두 번 예약하면 한 건만 남습니다. 지난 시간은 예약할 수 없습니다.
- 내 예약: 본인 예약만 취소합니다. 관리자도 예약을 취소할 수 있습니다.
- IT helpdesk: "문의 등록"에서 분류, 제목, 내용, 긴급도를 적고 접수합니다. 상태는 접수 → 처리중 → 완료 순서만 가능하고, 완료된 문의는 되돌리지 않습니다. 상태 변경은 관리자만 합니다.
- 규정 챗봇: 질문을 하나 적고 "답변 보기"를 누릅니다. 조문에 없으면 "규정에서 확인되지 않습니다. 관리자에게 문의하세요."라고 답하고, 규정과 상관없는 질문이면 "규정 질문만 답할 수 있어요."라고 안내합니다. 하루 20회까지입니다.
